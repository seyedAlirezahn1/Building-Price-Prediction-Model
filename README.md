# 📈 Linear Regression from Scratch

Building a simple house price predictor using only pure Python — no ML libraries, no numpy, no sklearn.

## 🧠 What it does

Predicts house price based on square footage using a line equation: `y = w·x + b`

## 🛠️ How it's built

- Calculates mean of X and Y
- Finds optimal slope (w) using least squares formula
- Finds intercept (b)
- Predicts price for new houses

## 🎯 Goal

Understand what happens behind the scenes of Linear Regression before using libraries like scikit-learn.
